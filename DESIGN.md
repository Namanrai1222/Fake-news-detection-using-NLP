# Design system

The interface borrows the clarity of an editorial review desk: a paper canvas, ink typography, fine rules, and a restrained red signal for actions and caution. The accent does not encode truth.

- Display type: Newsreader; body type: DM Sans.
- Palette: paper `#f4f5f3`, white surface `#fff`, ink `#1c292c`, muted `#58696a`, rule `#cbd2ce`, accent `#aa3f30`.
- Structure: shared navigation and footer; one clear content column for evidence, a two-column workbench for analysis, and visible limitations beside the form.
- Interaction: keyboard focus uses the red outline; reduced-motion preference removes transitions. Responsive layout stacks at 800px.
